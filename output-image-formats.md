# Formati immagine di output

### TIFF (16 bit)

16 bit (valore digitale per pixel compreso tra 0 e 65535) in formato TIFF (.tif).

### TIFF (32 bit, percentuale %)

Formato di output a 32 bit (pixel in virgola mobile da 0,0 a 1,0) in formato TIFF (.tif). I valori dei pixel rappresentano le percentuali di riflettanza dove 0,0 = 0% e 1,0 = 100%.

### **JPG (8 bit)**

8 bit (numero digitale pixel 0 -255) in formato JPG (.jpg).

### **PNG (8 bit)**

Output in formato PNG (.png) a 8 bit (numero digitale pixel 0 - 255). Compressione senza perdita di dati adatta alla visualizzazione sul web.
